# Screened yearly replay: revised acceptance rule

Approved scope: isolated `screen_default`, `screen_sub`, `screen_sub_failure` only. Historical `baselines/pre_cast_migration/*.json` are immutable.

A replay matches when the **multiset** of substantive events agrees by year, kind/type, parties, amounts and remaining semantic payload (ignoring event sequence/order and generated transaction IDs embedded in event receipts; those IDs are reported separately); project outcomes and dates agree; final account balances agree; and knowledge records, including year stamps, agree. Compare transaction economics (year, source, destination, amount, purpose, supplier location, asset location) directly as a multiset independently of transaction ID and order. Compare against the separately frozen `*_transactions.json` files captured from main `e20ad340709cc5f49f949bc9df396e46509cd3af` on 2026-10-11; do not regenerate references from live legacy code. Knowledge records, including year stamps, compare as a multiset; yearly knowledge must be non-decreasing by year. Report every differing field, including generated IDs and fingerprint, with reason. No change to baseline and no silent waiver of missing, additional, or altered substantive events.

The kernel `fingerprint()` hashes ordered `state.transactions` tuples including transaction ID, year, accounts, amount, purpose and locations, plus ordered FCF records, balances/assets and economic impacts. It does **not** directly hash Build 8 `event_log`. Thus event-log reordering alone leaves fingerprint unchanged; reordering kernel transactions or regenerating their sequence-dependent IDs may change it despite identical economics. Fingerprint differences must be explicitly disclosed, not treated as proof of a match.

First slice: one fresh opening, existing policy-backed Interlune/Axiom decisions, finite USA funds, fixed existing executor priority, authored pressure, Build 7 additional integration off, BUILD/LAND shared capacity, optional one-level subcontract and failure/recovery. No other experiment combination, defense, reactive race, or baseline rewriting. If a substantive multiset mismatch occurs, report the exact discrepancy and stop.
