# Defense capital draw (opt-in shared-kernel runtime change)

Default: **off**. No call, new account, event, transaction, or state change when disabled. This is an additive Earth-boundary draw, not a reallocation of the existing civilian pool. No military expenditure series is present in Earth v4's qualified country inputs or the investment boundary loader. The basis is an **authored investment-linked proxy**, not an estimate of actual defense budgets or military expenditure.

Single country-year dial table: `defense_draw_trial.DIALS` (2026–2035 USA/CHN). Overall scale 1, country scale 1, steepness 2, cap 0.01. `pressure_effective = min(1, pressure + sum(active crisis intensities))`; `curve = pressure_effective ** steepness`; `draw = (investment / model-currency-units) * cap * min(1, overall_scale * country_scale * curve)`. The ceiling is 1% of the admitted investment proxy, compared with the existing civilian `m_max=0.001` (0.1% of investment), so the defense ceiling is **10 times** the civilian ceiling. This is an illustrative capacity envelope, not empirical military calibration. At pressure 0.3, curve 0.09 makes the draw 0.09% of investment, or 90% of the civilian draw. At pressure 0.7, the draw is 0.49% of investment, 4.9 times civilian. The square curve avoids treating a minor threat as a full mobilization; the hard cap avoids unlimited extraction. All values are deliberately authored and revisable.

Crisis is a named declared input with countries, inclusive calendar years, and intensity; it is not a war simulation. Every active draw receipt and audit includes crisis names, pressure, curve, ceiling, amount, all four dials, seed and code version. Money moves from the country's existing Earth-boundary account to a distinct defense funds account; transactions and boundary net reconcile. One defense draw per country-year, independent of the existing one civilian draw. The country-year and investment assertion are validated before a draw.

The opt-in `run` and `sweep` exercises live in Build 8 as demonstration clients, not a new government Agent. `sweep` produces flat records suitable for CSV/charting. Example crisis: `USA_CHINA_SPACE_CRISIS`, USA and CHN, 2027–2029, intensity 0.4. Financier ranking is untouched. This mechanism alone does not produce rivalry, sponsor allocations, or executor crowding: those remain subsequent experiments.

**Scope limit:** The defense draw is additive to the existing Earth investment-derived capacity, so it does not represent an independently sourced military-spending stock. It is additional simulated model currency backed by the same admitted Earth investment assertion. It is not a historical military budget.

The optional draw lives in a separate shared runtime module `simulation/offworld_mvp/defense_capital.py` rather than inside the Build 7 `offworld_kernel` source tree. That placement is deliberate: Build 7 checks the hash of its executable kernel sources against an asserted commit, and even adding an unused file there invalidated the hash. No existing kernel function or source file is modified. The Build 8 client explicitly invokes the opt-in module. This preserves the source-integrity invariant without inventing a migration.
