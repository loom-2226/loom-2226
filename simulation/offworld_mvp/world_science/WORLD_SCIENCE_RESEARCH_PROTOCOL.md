# World Science Research Protocol

## Objective
Create a reproducible, provenance-bearing empirical constraint baseline suitable for conditioning future hidden-WORLD generation without inventing knowledge.

## Workflow
1. Bootstrap from live GitHub authority and inspect the current baseline.
2. Record repository identity, SQLite SHA-256, schema and validation state.
3. Archaeologically recover relevant existing LOOM evidence before adding new material.
4. Conduct independent current scientific research using primary/authoritative mission, archive and peer-reviewed sources where possible.
5. Load new findings as CANDIDATE assertions only.
6. Preserve ontology, uncertainty, source lineage, spatial/temporal scope, observation footprint and model status.
7. Update coverage and explicitly record UNKNOWN, conflict and missing evidence.
8. Register large spatial/mission products by metadata/provenance rather than embedding giant rasters or ephemeris series.
9. Assess WORLD-generator readiness as: REAL/empirically constrained; scientifically constrained unknown; genuinely unconstrained.
10. Run hostile validation.
11. Perform two clean deterministic rebuilds and require identical SQLite SHA-256.
12. Admission/freeze is a separate governed act. Research does not grant itself authority.

## AI role
AI may discover, triage, synthesize and stage candidate evidence. It must not write directly into an authoritative scientific plane without deterministic validation and governed admission. Research breadth is not permission to erase uncertainty.

## Mandatory hostile questions
- Was local/sample/footprint evidence globalized?
- Was detection converted to abundance, accessibility or reserve?
- Was model inference mislabeled as observation?
- Was a time-specific atmosphere/plume/activity made timeless?
- Were sparse-data bodies given invented precision for structural symmetry?
- Did any SCENARIO/HIDDEN_WORLD value enter scientific assertions?
- Did any generated or realized simulation state flow backward into REAL evidence?
- Does every admitted claim retain reconstructable source and scope lineage?

## Reproducibility
A campaign is incomplete if a clean rebuild is nondeterministic. Preserve the input/source manifest, schema, build code, validator, validation output and final database identity together.
