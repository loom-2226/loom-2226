# World Science to Offworld Runtime Interface

This contract is build-independent. Build 6D is the first qualified runtime architecture that makes the boundary concrete, but this science package is not owned by Build 6D.

## Causal seam
`empirical science -> governed constraint admission -> generation model/policy -> seeded SCENARIO hidden WORLD -> mission/instrument interaction -> REALIZED observation -> epistemic admission -> Agent-visible information -> belief -> decision -> action -> realized consequence`

## Context mapping
- Empirical scientific evidence belongs to REAL.
- A generator-selected hidden realization belongs to SCENARIO(id).
- Mission outcomes, extraction, infrastructure and settlement history belong to REALIZED(run_id).
- Agent information is a perspective-filtered subset produced through governed admission, never direct WORLD access.

## Generator requirements
A future generator must consume versioned empirical constraints, generation-policy identity and seed lineage. Known facts remain fixed/bounded at their legitimate scope. Scientifically constrained unknowns define admissible model families. Genuinely unconstrained properties may be fictionalized explicitly.

Whole-body generation should provide the lowest-resolution latent state needed for coherent cross-site behavior. Project-site generation may then resolve local stratigraphy, resource distribution, concentration, geometry, finite stock and accessibility conditional on the body realization and local evidence.

## Measurement rule
Generators create WORLD truth. Missions create INFORMATION.

A measurement function conceptually maps:
`hidden site WORLD + mission + instrument + location + epoch -> REALIZED observation`

Agents receive only admitted observations/evidence.

## Conservation and lineage
Every generated property used causally must identify generator/model version, empirical constraints, policy/version, seed and world identity. Every observation must identify the WORLD state/measurement process that produced it without exposing hidden values to the Agent perspective.

## Non-goals
This package does not define mining economics, reserves, markets, politics, detailed life support, technology evolution or settlement policy. Those systems consume world state through governed interfaces.
