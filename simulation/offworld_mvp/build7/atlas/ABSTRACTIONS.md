## Epistemic boundary that matters most

**WORLD_SIM physical truth -> noisy observation -> Agent information/belief -> policy decision -> system transition -> persistent consequence.** Do not shortcut the sequence in a diagram. A source-authored assumption can legitimately influence choices, but that does not make it a measured physical fact.

## Review discipline

When reviewing any placeholder, ask: (1) where exactly is the value defined? (2) what reads it? (3) which decision or transition changes if it changes? (4) what would be an invalid interpretation? A value that is configured but never consumed by the generated-world path must be labeled **configured / not demonstrated**, not drawn as an active cause. Nothing in this register authorizes replacement or redesign by itself.
