# LOOM design system (DRAFT v0.1.0)

Start with [the style guide](LOOM_STYLE_GUIDE.md). Canonical values and approval status are in [`loom-tokens.json`](loom-tokens.json). Web adapter: `loom-tokens.css`; Python adapter and validator: `loom_design.py`. Verify with `python design/loom_design.py --check` from repository root. The unbundled Montserrat font and subsystem status thresholds remain open; do not mark APPROVED. This design system is visual/asset authority only and does not supersede canon, science, governance, or runtime authority.
