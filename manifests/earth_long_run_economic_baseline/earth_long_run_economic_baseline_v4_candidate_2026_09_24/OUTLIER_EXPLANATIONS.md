# Hostile descriptive review of named outliers

Values here are inherited constant-2015-USD-scale **model proxies**, not 2226 purchasing-power USD or physical capacity. `DESCRIPTIVE_STATISTICS.json` surfaces the complete distributions, ranks, negative growth, low replacement coverage and extreme values without modifying any country outcome. All named cases use the same central demographic and economic rules.
