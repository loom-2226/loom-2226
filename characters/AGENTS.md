# Character subtree agent rules

Applies to `characters/**`.

## Status

Character material is current campaign/companion material within its declared scope. Do not assume every character file is a governing world-physics source.

Before mutation:

- preserve established characterization and continuity unless the work item explicitly changes it;
- distinguish observed behavior from invented hidden psychology;
- distinguish in-universe character canon from governance persona/metaphor;
- check whether a character change has gameplay/mechanics implications.

## Walter-specific firewall

The governance WALTER autonomous assurance agent is inspired by and constrained by established Walter characterization, but governance-agent evolution does not automatically retcon the in-universe Walter character.

Likewise, game-character developments do not automatically alter WALTER governance policy.

Walter remains nonverbal unless governing character canon is deliberately changed through the proper process.

His behavior should communicate agency through movement, posture, proximity, attention, refusal, protective action and object choice rather than invented dialogue or hidden omniscience.

## Provenance

When a character trait is claimed to be established, prefer the current character source or documented continuity rather than inventing a memory-compatible detail.
