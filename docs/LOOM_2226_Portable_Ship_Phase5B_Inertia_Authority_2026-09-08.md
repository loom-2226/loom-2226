**Date:** 2026-09-08

## 1. Purpose

Phase 5B establishes the rotational mass-property convention and audits what Wayfarer inertia is actually supported by current governed data before any full-vehicle rotational 6DOF is admitted.

No renderer geometry, visual envelope, placeholder dimension, chat assumption or nominal hull envelope may silently become inertia authority.

## 2. Mechanics convention

LOOM uses the conventional aerospace/classical rigid-body mass-property formulation:

- SI units: kg, m, kg m^2;
- right-handed body frame;
- symmetric 3x3 inertia tensor expressed about the instantaneous vehicle center of mass;
- component inertia defined about the component centroid in its local frame;
- component inertia rotated into the vehicle body frame before aggregation;
- parallel-axis theorem applied from each component centroid to vehicle CoM;
- attached/detached components and mutable stores update mass, CoM and inertia consistently;
- Euler rigid-body rotational dynamics use `I * omega_dot + omega x (I * omega) + I_dot * omega = tau` when inertia changes.

Tensor convention:

```text
I = [[ Ixx, Ixy, Ixz],
     [ Ixy, Iyy, Iyz],
     [ Ixz, Iyz, Izz]]
```

with off-diagonal entries generated by the dyadic form

```text
I_parallel = m * ((d dot d) * Identity - outer(d,d))
```

so no separate sign convention for products of inertia is hidden in the implementation.

## 4. Current Wayfarer authority finding

Current Phase-3 Wayfarer mass authority provides qualified total mass, component/store centroids and configuration semantics. The schema can carry centroidal inertia, but the current fixed mass-element rows do not contain complete centroidal inertia tensors.

The current mutable stores use a `POINT_MASS` inertia model in the prototype. That is a prototype modeling declaration, not evidence that the physical stores literally have zero centroidal inertia.

Phase-4 geometry contains useful governed/design-baseline dimensions, but several geometry components are separate visual/geometry rows rather than the same physical mass components. Therefore geometry cannot simply be multiplied by mass to manufacture a full vehicle tensor.

## 5. Admissible partial result

The current data can determine the **parallel-axis contribution** from known masses and centroids:

```text
I_total = I_parallel_axis_known + I_centroidal_unresolved
```

`I_parallel_axis_known` is useful qualification evidence and must be deterministic.

It is **not** a complete Wayfarer inertia tensor and must never be handed to the 6DOF propagator as if it were one.

The especially important diagnostic is roll inertia about X: because most current mass centroids lie on the thrust axis, a point-mass-only model drastically understates `Ixx`. This makes silent use of the partial tensor physically unacceptable.

## 6. Gate rule

Full Wayfarer rotational 6DOF remains fail-closed with:

```text
WAYFARER_INERTIA_OPEN_NOT_QUALIFIED
```

until a governed centroidal mass-distribution model is established for enough physical mass to produce a complete, positive-definite, configuration-aware tensor with explicit provenance.
