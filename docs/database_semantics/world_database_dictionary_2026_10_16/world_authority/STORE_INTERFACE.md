# World Authority V1 fixed store surface

The store imports no Offworld/kernel module. `SQL_COLUMN_PROFILE` and `SQL_PRIMARY_KEYS` are a closed literal representation of the pinned migration, not runtime reflection, an ORM, a world-entity registry or a generic ontology. Caller values are bound parameters; table/column identifiers must be in that exact catalog. Optional SQL fields omitted by a trusted producer become explicit NULL projections; required fields never default. Source import plans expand to every SQL column and reconciliation compares all cells.

All public writers take a psycopg3 connection authenticated for the named service. They use SERIALIZABLE transactions and immutable insert-or-full-match; no arbitrary SQL callbacks. Neutral byte SHA checks do not replace consumer fingerprints or serializers. Domain-specific original decoders, conservation, kernel trace validity, worker fingerprint and safe projection attestation remain the future consumer's existing qualified responsibility. No simulation outcome is calculated by the store.

- `plan_sqlite_import(path, expected_sha, *, source_commit, source_path)`: no DB writes; exact accepted snapshot only.
- `import_exact_snapshot(connection, plan)`: one atomic source transaction; `IMPORTED` or `ALREADY_MATCHED`.
- `verify_source_projection(connection, plan)` and `export_source(connection, plan, directory)`: every planned full row/raw cell, deterministic logical export.
- `verify_original_bytes(bytes, sha256)`: exact original payload integrity; no consumer digest algorithm substitution.
- `read_catalog_location(connection, body_key, location_key)`: separately permissioned reference reader, immutable tuple or absent. No Agent invocation.
- `read_admitted_constraints(connection, assertion_ids, cutoff, use_contract, target_support_ids, *, consumer, context, perspective)`: explicit REAL, trusted perspective, pinned use/standing and recursive parent/support closure. Returns preserved source projections; BLOCKED on unauthorized use or unsupported scope. Does not upgrade initial source standing.
- `install_exact_world(connection, ordered_table_column_pairs)`: world-writer role only; fixed wa_world tables, no generator/science/runtime writes. A repeated realization requires complete immutable match; no partial repair.
- `load_bound_world(connection, run_id, binding_key, *, context, effective_time)`: trusted runtime only; explicit REALIZED binding and physical history through causal event time. Does not grant Agent access or create defaults.
- `persist_epoch(connection, run_id, epoch_id, expected_previous_head, ordered_table_column_pairs, terminal_artifact_refs)`: execution login must possess only the separately supplied runtime/admission writer memberships. Original consumer builds/validates the complete batch before this call. The caller may already hold its required SERIALIZABLE transaction/per-run lock before kernel execution; the store checks isolation, exact previous head, immutable projections, original-byte hashes, final original refs and trace edges, then commits. It executes no transition. A replay compares immutable rows and never rewinds current principal bindings. Returned `COMMITTED`/`ALREADY_MATCHED` follows COMMIT; failure rolls back. Consumer discards/replays its uncommitted kernel after failure or unknown acknowledgement.
- `read_replay_prefix(connection, run_id, *, input_snapshot_ref, code_contract, code_tree_sha256)` and `export_run(...)`: ordered private originals/full SQL projections under trusted runtime/auditor routes; consumer's fixed decoder proves original semantic closure. Export requires auditor membership. SQL range values export with explicit lower/upper/bounds/empty fields; they never become another clock.
- `load_current_agent_snapshot(connection)`: no caller run/actor/time override; authenticated Agent-only safe current snapshot and admitted fact view. No raw worker SQL API is exposed.
- `record_fixture_admission(connection, manifest)`: separate governor only; never called by ETL. Exact manifest keys: profile `WA_FIXTURE_ADMISSION_MANIFEST_V1`, assertion_id, assertion_metadata_sha256, support_id, source_snapshot_sha256, initial_standing, use_contract_ref, authorization_ref, decision_ordinal, standing, effective_availability_lexeme, time_support. UUIDs are canonical strings, ordinal a positive integer, standing ADMITTED/HOLD; exact hashes/source initial CANDIDATE remain bound. time_support has all nine SQL lexical fields, with LEXICAL/SIM_TIME and no parsed scientific epoch. The time tuple, excluding derived UUID, is hashed in the manifest to avoid recursion. IDs follow the owner-pinned fixture identity recipe. Science writer must first install exact time metadata; governor gains no geography or raw source write rights. Occupied unequal ordinal fails. Synthetic tests exercise this route only in the separate security database; baseline science remains unadmitted.

Future Build 6E supplies complete consumer-validated originals and deterministic FK-ready batches. This package implements only domain access/transactions and their qualification; it neither implements the future Offworld compiler nor runs a qualification simulation. Trusted services/DBA/auditor can inspect private state; they are explicitly outside Agent containment. RLS, schema grants, NOLOGIN groups and safe views contain Agent service principals.
