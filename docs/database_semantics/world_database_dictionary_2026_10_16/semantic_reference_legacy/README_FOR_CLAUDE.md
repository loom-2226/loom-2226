# Claude: read this before deriving from LOOM databases

Kevin's instruction is simple: **we built these databases, so their meaning should be explainable from GitHub. Do not make shit up when the explanation has not yet been recovered.**

Before deriving a world object, relationship, dependency, character role, economic fact, demographic fact, or narrative consequence from either production database:

1. read the semantic dossier and index in this directory;
2. check the table/field status;
3. read existing CIVSTATE self-documentation where applicable;
4. recover the GitHub builder/consumer if the field remains unresolved;
5. check scope (body/region/zone/facility/organization/person) and grouping-level variation;
6. record the weakest semantic/provenance link;
7. if unresolved, stop that derivation or explicitly quarantine it as a hypothesis.

The point of this directory is not to make Claude timid. It is to let Claude move faster **without repeatedly rediscovering what the database meant after using it incorrectly**.
