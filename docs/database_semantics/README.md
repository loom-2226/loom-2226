# LOOM Database Semantics

This directory is the production semantic contract for the LOOM world databases.

**Start here:** `LOOM_DATABASE_SEMANTIC_DOSSIER_v0.1.md`.

Agents must not infer intended database meaning from identifiers or value patterns. The full dossier enumerates all tables in the verified runtime inventory and explicitly marks unresolved semantics. The machine-readable index exists so coverage can be checked without memory.

This documentation is subordinate to canon/engineering/data authority and does not promote database contents to canon. It describes the storage/model contracts currently recovered.
