## Discovered causal blocker

This is correct, but it exposes a missing causal object: PROJECT HYPOTHESIS FORMATION.

An Earth country-sector opportunity is contextual economic state. It does not specify:
- a concrete product/service/project objective;
- origin/destination/site;
- quantity/capacity;
- provider capability requirement;
- transport mission/service class;
- certification claim/domain;
- regulatory/access scope;
- project cost or schedule.

Without those fields, the hard authorities cannot be queried honestly. Treating a generic AUS:BULK_MATERIALS context as though it were already a lunar-resource project would manufacture the very causality the actor architecture is intended to earn.
