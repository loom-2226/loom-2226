## Framing

LOOM is best treated as a provenance-preserving, multiscale, multimethod world simulation in which agent-based simulation is one execution layer, not the whole system.

Two governing research principles are:

> Use the cheapest representation that preserves the causal claim being made.

> Resolution follows causal sensitivity, not ontology.

Hard simulation state remains outside generative models. An LLM may later serve as a bounded cognition generator for selected active actors; it is not the simulation kernel.

## Adaptive representation hierarchy

- **Level 0 — global fields:** climate, commodity prices, technology capability, demographic rates, geopolitical state, orbital environment, energy availability.
- **Level 1 — aggregate/cohort populations:** statistical or cohort state where individual identity is causally irrelevant.
- **Level 2 — lightweight synthetic individuals:** persistent enough for household/life-course or distributional effects without expensive cognition.
- **Level 3 — active consequential agents:** promoted when an event makes individual or organizational decisions causally material.
- **Level 4 — persistent high-fidelity/narrative actors:** retained when identity, memory, relationships or repeated decisions materially affect history.

Promotion and demotion are explicit state transitions. A cohort member may become a synthetic individual, then an active agent, then a persistent high-fidelity actor. Expensive cognition may cease while canonical state persists.

## Event-driven causal execution

Long-duration propagation should increasingly advance to the next causally relevant event rather than blindly waking every entity on every universal timestep.

Conceptual execution:

authoritative state
→ detect causal opportunity or pressure
→ activate relevant subsystem
→ promote affected entities
→ resolve event
→ write consequences and provenance
→ demote/collapse state where justified
→ advance to next event

The Timeline is central. A technology-frontier event is a consideration trigger, never an automatic capability unlock.

Example:

TRN-MOD-NEP frontier event
→ identify affected actor set
→ access/adoption decisions
→ actor capability events
→ engineering/transport opportunities
→ projects/missions/services
→ downstream civilization consequences

The existing group-actor inventory and future conflict actors should therefore remain mostly dormant stateful entities. Technology frontiers, commodity shocks, certification requests, labor conflict, infrastructure failure and political crises wake only the relevant causal neighborhood.

## Multimethod execution

Candidate methods include scientific ABM, synthetic populations, discrete-event and parallel discrete-event simulation, multiscale models, network models, statistical/state-space models, authoritative physics/engineering calculators, and selective generative cognition.

Method choice follows the causal claim. Physics and engineering calculators retain authority over physical feasibility. Statistical/cohort models retain authority where population-level claims do not require individual simulation. Generative cognition cannot overwrite hard state or manufacture missing physical authority.

## Verification, validation and backtesting

Verification asks whether LOOM implemented the declared model correctly. Validation asks whether that model reproduces the phenomenon it claims to model.

Validation should be hierarchical:
1. agent/component level;
2. model/system level;
3. output/distribution level.

Historical backtesting should become an explicit qualification lane, including windows such as 2000→2025, 1990→2010 and 2000→2020, using only information available at the starting date where practicable.

Do not demand magical prediction of unique black swans. Compare distributions and trajectories such as population, GDP, urbanization, technology adoption, energy mix, life expectancy, migration, trade, military expenditure, fertility, infrastructure, emissions and transport.

## Ensemble futures

Future state should be treated conceptually as P(S[t+n] | S[t], M), not merely one deterministic future. A canonical 2226 history may select one realization while retaining ensemble context and the assumptions/model identity that generated it.

## Causal provenance

Every major generated historical development should retain enough ancestry to answer: **why did this happen?**

event
← conditions
← decisions
← prior state

Reason-coded exclusions and explicit UNKNOWN states are part of causal provenance, not diagnostic clutter.
