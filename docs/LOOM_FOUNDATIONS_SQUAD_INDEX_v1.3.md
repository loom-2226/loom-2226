## New Freaks architectural contribution

The expanded roster makes the full anomaly-information path explicit:

`event/report -> fieldwork -> instrument/artifact -> source/intermediary -> edited release -> public feedback -> archive -> skeptical reanalysis`

This primarily raises P1/P5/F5 value and makes P4's methodological gate stricter. It does not raise the scientific status of anomaly claims.
