## Three-squad convergence

A convergence is a **priority signal, not an evidence multiplier**:

1. Freaks identify a recurrent/well-provenanced pattern.
2. Unsupervised formulate a structural hypothesis/reframing.
3. Red Pens define observables, nulls, discriminators or a kill test.

Only independent evidence changes scientific status.
