DATA_SET_DESCRIPTION Data Set Overview : This shape model of asteroid Ceres is based on images taken from Jan 2015 to October 2015 by the Framing Camera (FC2) on the Dawn spacecraft. Additional information about the method for deriving the model may be found in [GASKELLETAL2008], [GASKELL2005] and [GASKELLETAL2007]. The version of the model included here was prepared on December 19, 2017 and updated on October 19, 2018. A high-resolution global topography model of Ceres was determined as a part of Dawn gravity science investigation using the Stereo-photoclinometry (SPC) technique developed at the Jet Propulsion Laboratory by processing Dawn's Framing Camera data acquired during Approach to post-Low Altitude Mapping Orbit (LAMO) phases of the mission. A total of about 38,000 images were processed with image resolutions ranging from 35.6 km to 35 m. The Approach and Survey data were mainly used to compute the a priori shape model and were not used to compute the final global topography model as their contribution was almost negligible. The final topography (the current delivery) model was produced with 100-m ground sample distance using images with 140 m and 35 m pixel resolutions acquired during High Altitude Mapping Orbit (HAMO) to post-LAMO phases of the mission. This process required approximately 64,000 individual maps to completely cover the entire body, including partial overlap between maps that is essential to tie neighboring maps together. The details of this particular shape model and reference is: Park et al., High-resolution shape model of Ceres from stereophotoclinometry using Dawn Imaging Data, accepted for publication, Icarus, 2018. Data : The models were originally prepared in the Implicitly Connected Quadrilateral (ICQ) format, and files are provided in the DATA/ICQ directory. The filenames are of the form CERES_xxxyymmdd_qqqq.ICQ, where 'TTTTT' is the applicable body (VESTA or CERES), 'xxx' is the origin of the shape model (nominally SPC, Stereo-photoclinometry), 'yy' is the creation year, 'mm' is the creation month, 'dd' is the creation day, and 'qqqq' is the resolution of the model. A text file, 'ICQMODEL.ASC' is provided in the DOCUMENT directory which describes the ICQ format. The DATA directory also contains two additional files: CERES_xxxyymmdd_PATCH.TAB - lists the locations (latitude, longitude) where no camera data were usable in generation of the shape model at that location (e.g. the surface was in shadow or no images where taken). In these locations, the shape was patched with the Ceres reference ellipsoid : [482.0, 482.0, 446.0] km. FC2_IMAGES_USED.TAB - This file lists all the Framing Camera 2 (FC2) images used in the development of the Dawn Ceres SPC shape models. It is recommended that you use the following SPICE kernels when using this product: dawn_v14.tf (or later) : Ceres Surface name/ID mappings dawn_ceres_grv171219_v1.tpc : Ceres rotation parameters de432.bsp : Planetary ephemeris sb_ceres_grv_171219.bsp : Ceres ephemeris wrt Sun dawn_grv_150204_150424_171219_v1.bsp : Dawn ephemeris wrt Ceres dawn_grv_150424_150701_171219_v1.bsp : Dawn ephemeris wrt Ceres dawn_grv_150813_151023_171219_v1.bsp : Dawn ephemeris wrt Ceres dawn_grv_151213_160902_171219_v1.bsp : Dawn ephemeris wrt Ceres dawn_fc2_150818_160827_grv171219_v1.bc : Dawn FC2 orientation The GEOMETRY directory contains a meta-kernel of these recommended kernels. The 'SPICE_OMNIBUS_MM_SIS.PDF' document is provided in the DOCUMENT directory which describes the SPICE system, where to get the toolkit, and basic use. The coordinate system of the model is described by the SPICE PC Kernel entitled 'DAWN_CERES_GRV171219_V1.TPC', available on the Navigation and Ancillary Information Facility (NAIF) Dawn archive. The pole is derived from Gravity Science observations [PARKETAL2016]. The volume archive Software Interface Specification (SIS) document describes the format and content of the archive. HTML and PDF versions of the document are provided in the DOCUMENT directory with the name 'DAWN_SPC_SHAPE_MODEL_SIS'. Data Coverage and Quality : This volume contains the shape models derived by the Dawn Gravity Science Team at JPL using the SPC image processing technique as described above. The models are provided in 128, 258, 512, and 1024 resolutions in the DATA/ICQ directory. The complete list of images used is in the DATA directory with the filename FC2_IMAGES_USED.TAB. It has a corresponding PDS3 Label entitled FC2_IMAGES_USED.LBL. Although nearly all clear-filter images from the Ceres encounter were used, certain images which have non-opnav exposures (e.g. very long star stares) or were nearly black on the limb were excluded and not usable for shape model generation. CONFIDENCE_LEVEL_NOTE Confidence Level Overview : The shape models contained within this dataset are believed to be of good quality. The user should make note of the following: All archived HAMO and LAMO clear filter science images were used in generation of the shape model. A full list of images used is available in the DATA directory. The average total height error of the final global topography model is 10.2 m and 88.9 percent of the surface has the total height error below 20 m. In certain locations on the surface, no image data were usable in generation of the shape model due to shadowing, unresolved limb profile, or degraded image quality. In these locations, the Ceres reference ellipsoid was used to patch the shape model. A data product is provided in the DATA directory that describes the locations of the ellipsoid patches.
